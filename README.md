# 手写签字 Web App

纯前端手写签字应用，无需服务器，文件不上传，数据安全。

## 功能

- 上传 .docx / .pdf 文档
- 在文档上拖拽框选签字位置
- 手写签名（支持触摸和鼠标）
- 签名贴入框选位置
- 下载已签字 PDF 文档

## 使用方式

1. 上传 Word 或 PDF 文档
2. 在文档上拖拽框选签字区域
3. 点击框选区，手写签名
4. 确认签名，签名贴入文档
5. 下载已签字 PDF

## 技术栈

- PDF.js - PDF 渲染
- docx-preview - Word 文档渲染
- pdf-lib - PDF 编辑（贴入签名）
- html2canvas - DOCX 页面截图
- 纯前端，零服务器依赖
